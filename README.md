# 🚀 QueraList Landing Page

A modern, responsive, and pixel-perfect landing page for **QueraList** (a task and time-management productivity app), built using modern semantic HTML5 and styled with Tailwind CSS.

🔗 **Live Demo:** [landing-page-psi-lime-49.vercel.app](https://landing-page-psi-lime-49.vercel.app/)

---

## 📸 Overview

QueraList is designed to help users organize their daily routines and achieve their goals effectively. This repository hosts the official front-end landing page, highlighting key features, download options, user testimonials, and call-to-action sections.

---

## ✨ Features

- **Responsive Design:** Fully responsive layout optimized for mobile, tablet, and desktop screens.
- **RTL Support:** Complete Right-to-Left (RTL) orientation tailored for Persian typography and UI flow.
- **Semantic HTML5:** Built with SEO and accessibility best practices in mind.
- **Tailwind CSS Styling:** Clean, maintainable, and utility-first styling architecture.
- **Clean Structure:** Modular sectioning (Hero section, Features, App download, Testimonials, and Footer).

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic elements)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Deployment:** [Vercel](https://vercel.com/)
